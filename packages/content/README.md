# IINB canonical content

This directory is the only canonical source for the Ignorance Is Not Bliss manuscript and shared reader media.

- `chapters/` contains ordered chapter Markdown with front matter.
- `parts/` contains the three part-title sections.
- `dedication.md` contains the dedication page.
- `glossary.json` contains structured glossary entries.
- `images/`, `audio/`, and `logos/` contain reader assets shared by web and native.
- `islands-info.json` and `more-from-ethan.json` contain shared ecosystem copy.

The native JSON and asset maps are generated by `npm run build:native-content` from the repository root. Do not treat generated files under `apps/native/` as manuscript sources.

The public access contract is currently: the Preface and Chapter 0 are free; every other chapter requires the `ignorance-is-not-bliss` entitlement.
